# 彩雾作品库

《深空当铺》彩雾喷罐 Mod 的玩家图案库。作品投稿、审核、目录和下载均在 GitHub 上完成，无需独立服务器。

- **下载使用**：喷罐 → 作品库 → 在线作品 → 下载 → 本地图案 → 预览并应用。下载不需要登录 GitHub；已下载和已应用的图案可离线使用。
- **上传作品**：游戏内“分享作品”导出投稿文件，再按[投稿说明](CONTRIBUTING.md)上传到 GitHub，提交 Pull Request。审核合并后自动上架。
- **作品目录**：[catalog.json](catalog.json)。图片位于 `works/作品编号/image.png`，预览位于同目录 `thumbnail.png`。目录、元信息和文件均可直接下载。
- **我的上传**：在 Mod 连接设置填自己的 GitHub 账号名，按账号筛选；真正的投稿/下架身份以 GitHub 登录账号为准。

默认仓库地址：`https://github.com/qq1270021689-max/pawnshop-spray-gallery/`。

仅投稿自己有权分享的纯图案。不要上传人物底图、游戏原始素材、存档、程序、密码、令牌或个人资料。作品归原作者；上传目的为在本 Mod 中供其他玩家下载使用，不将其他人的图案冒充自己的作品。若你不同意公开图案，请勿投稿。

示例色卡由本项目生成，用于确认下载与透明图案流程，不包含游戏素材。墙画、柜台、纹身、人物和手机外壳按画布分类。下架会移除当前目录和文件，Git 历史或他人已下载副本可能仍保留。

## 维护者

1. 查看投稿PR中“Artwork submissions / validate”结果，核对图案和权属后合并。
2. 合并触发发布任务，校验并重新编码图案、生成缩略图、更新目录。目录只记录 GitHub 验证的投稿账号，作者名不能代替账号身份。
3. 本人的下架申请或仓库所有者提交的下架申请才会通过。任务失败可在 Actions 手动输入已合并的PR编号重新处理；同一投稿不会重复上架。
4. 投稿流程只运行主仓库的可信工具，将投稿当数据读取，不检出或运行投稿分支的代码。无需手工配置长期写入密钥，GitHub Actions使用其临时仓库令牌。

当前单图不超过8MB、边长不超过2048像素；目录最多1000件，当前有效图案容量上限512MB。累计Git历史也占空间，接近容量时需维护或分库。GitHub网络、可用性和平台限制仍适用。
